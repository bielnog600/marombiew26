- Meal options live on each canonical meal as optional `options` (max 3): option 1 (`source:'plan'`) always mirrors `meal.items` and is re-synced by `syncMealOptions` in the editor and in `buildPublishedSnapshotPlan`, options 2/3 (`source:'bank'`) are picked and scaled by the pure `src/lib/mealBank` rules from `meal_bank`/`meal_bank_items`, so day targets, rebalance and publication keep using `items` only and diets without `options` stay unchanged.
- The student's choice is display state, not an edit: `MinhasDietas` stores it per weekday/meal in `student_diet_overrides.edited_meta.__options` and swaps the default foods through `applyStudentMealOptions` (day target stays from option 1); switching a weighed meal inserts a `planned.cleared` weigh log that `latestWeighLogs` hides, so history is never deleted.
