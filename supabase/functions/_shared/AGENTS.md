- Every AI call (Claude, OpenAI, Lovable AI, ElevenLabs) goes through `aiFetch`/`anthropicChat` inside a handler wrapped by `withAiUsage(feature, fn, ...)` (`aiUsage.ts`); usage is priced by the pure `aiCost.ts` from `ai_model_prices` at call time and inserted with the service role in the background, so logging never delays or breaks a response and a new function that skips the wrapper fails `src/test/aiCosts.test.ts`.
- Usage rows keep `student_id` only for the student's own calls and `target_student_id` for whom an admin/system call was made, so per-student costs include plans generated for them without mislabelling who used the app.
